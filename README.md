# 🎵 팝송 문법 활동지 생성기 (v2)

2022 개정 영어과 교육과정 **[별표 4] 의사소통에 필요한 언어 형식**이 들어간 팝송을 YouTube 영상으로 찾고,
그 곡으로 **가사 빈칸 + 단어 활동 + 정답지**를 만들어 내려받거나 사이트에서 바로 정답을 확인하는 교사용 도구입니다.

## 사용 흐름

| 단계 | 하는 일 | 대기 시간 |
|---|---|---|
| 1. 표현 선택 | 대분류(40개 범주)·소분류(133개 세부 표현) 드롭다운 또는 이름 검색, 적용 학년 선택 | 없음 |
| 2. 영상 고르기 | 표현별 3~6곡(기본 목록 94곡 + AI 추천) + 재생 가능한 YouTube 영상 | AI 사용 시 5~20초 |
| 3. 가사·옵션 | 가사 붙여넣기(네이버·Genius 검색 버튼), **AI 구간 표시 붙이기**([Verse]·[Chorus]), **AI 해석 채우기**, 빈칸 수·Part 1/2 형식 선택 | AI 사용 시 5~30초 |
| 4. 확인·다운로드 | 미리보기 / 온라인 정답 확인 / 빈칸·단어 편집, DOCX·PDF 저장 | AI 사용 시 15~40초 |

4단계에는 크게 볼 수 있는 **수업 영상**(접기/펼치기, 다른 영상 전환)이 활동지 위에 표시됩니다.

곡별 임시 보관: 같은 곡을 다시 만들 때 AI가 만든 곡 소개·표현 설명·해석·단어 뜻(교사가 고친 내용 포함)을 이 브라우저에 14일간 보관해 다시 요청하지 않습니다(최근 15곡, 3단계에서 지우기 가능).

Part 2는 빈칸 단어 중 일부만 사용합니다(단어 찾기 12, 비밀 암호 8, 철자 섞기 10). ‘사라진 철자’는 빠진 철자를 순서대로 모으면 가사 속 구절(예: IF I WERE A BOY)이 완성되도록 단어를 고릅니다.

온라인 정답 확인: 가사 빈칸 · Part 1 · Part 2(단어 찾기는 첫 글자→마지막 글자 클릭) 모두 채점(전체 또는 Part별 채점·정답 보기), ‘눌러서 정답 보기’ 모드, 번호를 누르면 그 칸 정답 보기, 글자 크기 80~200%.

활동지 구성: **1쪽** 곡 정보(영상 QR)+가사 빈칸·해석 → **2쪽** Part 1 Vocabulary Check + Part 2 단어 활동(단어 찾기/비밀 암호/사라진 철자/철자 섞기) → **3쪽 이후** 정답(빈칸, Part 1, Part 2, 정답 표시 가사).

js/ai-tasks.js        AI 요청 문구와 응답 검증
js/youtube.js         영상 재생(오류 시 다음 영상 자동 전환)

lib/providers.js      OpenAI·Claude·Gemini 연결(서버·브라우저 공용)
api/llm.js            AI 요청 중계(Vercel 함수, 키 저장 안 함)
api/youtube.js        YouTube 영상 찾기 + 삽입 가능 여부 확인

## 배포 방법 (GitHub → Vercel)

1. **GitHub에 올리기**
   - GitHub에서 **New repository** → 이름 입력(예: `popsong-worksheet`) → Create.
   - 저장소 화면의 **uploading an existing file**(또는 Add file → Upload files)을 누르고,
     압축을 푼 폴더 **안의 내용물 전체**(index.html, api, css, js, lib, vendor, vercel.json …)를 끌어다 놓은 뒤 **Commit changes**.
   - ⚠ `api/`, `lib/`, `vendor/` 폴더가 빠지지 않았는지 확인하세요. `index.html`이 저장소 맨 위에 있어야 합니다.
2. **Vercel에 연결**
   - vercel.com → **Add New… → Project** → 방금 만든 저장소 **Import**.
   - Framework Preset: **Other** (Build Command·Output Directory는 비워 둠) → **Deploy**.
3. (선택) **Settings → Environment Variables**에 `YOUTUBE_API_KEY`(YouTube Data API v3 키)를 넣으면 공식 검색 API로 영상을 찾습니다. 없어도 동작합니다.
4. 이후 GitHub에 파일을 다시 올리면 Vercel이 자동으로 다시 배포합니다.

### 내 컴퓨터에서 미리 보기
Node.js 18 이상이 설치되어 있다면 폴더에서 `node dev-server.mjs` 실행 후 http://localhost:3000 접속.

## AI API 키

- 상단 **AI 설정**에서 **제공사 선택(드롭다운) → 키 입력 → 연결 확인** 순서로 사용합니다.
- **드롭다운 방식을 채택한 이유**: 키 모양만으로 자동 판별하면 `sk-`로 시작하는 Claude 키(`sk-ant-`)와 OpenAI 키가 섞이거나, 프록시·조직 키처럼 형식이 다른 키에서 오판할 수 있습니다. 그래서 교사가 직접 고르고, 입력한 키 모양이 선택과 다르면 “Claude 키처럼 보입니다 → 변경” 안내만 띄웁니다.
- 모델은 **‘목록’ 버튼으로 내 키에서 실제 사용 가능한 모델**을 불러와 고릅니다(빠르고 저렴한 모델이 맨 위). 모델이 종료·변경되어도 코드를 고칠 필요가 없습니다.
- 상태 표시: **키 미설정**(키 없음) / **연결 미확인**(키는 있으나 아직 요청 전 — 새로고침·키 변경 시에도 이 상태) / **요청 성공**(실제 생성 요청 성공 — OpenAI는 Responses API) / **연결 실패**(원인 안내: 키 오류, 크레딧 부족, 권한·지역, 모델 없음, 요청 과다, 서버 혼잡, 네트워크, 시간 초과).
- 키는 브라우저에만 저장됩니다(기본: 탭을 닫으면 삭제, ‘기억하기’ 선택 시 유지). Vercel 함수는 요청을 중계만 하고 저장·기록하지 않습니다.
- 키가 없어도: 기본 곡 목록 추천 + 자동 빈칸 + 단어 활동 + 정답지가 만들어집니다(단어 뜻·해석은 직접 입력).

### 고친 문제: AI 요청이 모두 거부되던 현상 (v2.1)
OpenAI의 JSON 응답 모드는 **입력(input)에 ‘json’이라는 단어가 반드시 있어야** 하고, 시스템 지시문(instructions)에 있는 것은 인정하지 않습니다. 연결 확인 문구에는 JSON이 있어 성공했지만, 실제 추천·해석 요청 문구에는 없어 400 오류로 거부되었습니다. 이제 모든 요청에 자동으로 붙이며, 거부되면 원인이 된 옵션을 빼고 한 번 더 시도하고, 오류 화면에 제공사 원문 메시지를 함께 보여 줍니다.

## YouTube 재생

- 서버가 영상 후보를 찾은 뒤 **oEmbed로 ‘다른 사이트 삽입 가능’ 여부를 확인한 영상만** 보여 줍니다(공식 영상 우선, 그다음 가사·한글 해석 영상).
- 재생 중 오류(삽입 금지 101/150, 설정 오류 153 등)가 나면 **다음 후보로 자동 전환**합니다.
- 2025년 이후 자주 생기는 **Error 153**(참조자 정보 누락)을 막기 위해 `Referrer-Policy: strict-origin-when-cross-origin`을 설정했습니다(vercel.json, index.html).
- 학교망에서 YouTube가 막힌 경우에는 ‘YouTube에서 보기’ 링크와 활동지 QR 코드를 이용하세요. 원하는 영상 주소를 직접 붙여 넣을 수도 있습니다.

## 가사와 저작권

가사는 사이트에 저장하지 않고 교사가 2단계에서 붙여 넣습니다(네이버·Genius 검색 버튼 제공). AI가 가사를 ‘기억해서’ 쓰게 하면 틀린 가사가 나오거나 제공사가 응답을 거절하는 경우가 많아, 붙여 넣은 가사를 기준으로 빈칸·해석을 만들도록 했습니다. 수업 목적 범위에서 사용해 주세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 영상 카드에 “영상 검색 서버에 연결할 수 없습니다” | Vercel 배포 주소에서 열었는지, `api` 폴더가 올라갔는지 |
| 연결 실패 – API 키가 올바르지 않음 | 제공사 선택과 키 종류가 맞는지, 앞뒤 공백 |
| 연결 실패 – 크레딧(잔액) 없음 | 제공사 결제 설정(OpenAI·Anthropic은 선불 크레딧 필요) |
| 연결 실패 – 모델을 찾을 수 없음 | ‘목록’ 버튼으로 모델 새로 불러오기 |
| 활동지 생성이 60초를 넘어 실패 | 빈칸 수를 줄이거나 빠른 모델(mini/flash/haiku) 선택 |
| 1쪽에 가사가 다 안 들어감 | ‘1쪽에 맞추기’, 해석 끄기, 가사에 [Chorus] 표시 넣기 |
